# h10-capture

The Polar H10 capture page for [Vagus Listener](https://github.com/JEMINT/GenAI) — one HTML file, Web Bluetooth, no backend.

**Live:** https://jemint.github.io/h10-capture/

Open it in **Chrome** on a Mac or **Bluefy** on an iPhone (Safari has no Web Bluetooth). Everything you record stays in that browser; nothing is uploaded.

This repo exists only to give the file an HTTPS address. The source of truth, tests, and the Python ingestion live in the main repo under `vagus-listener/tools/h10-capture/`.
